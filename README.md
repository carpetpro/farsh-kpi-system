# شبکه فروش هوشمند فرش — داشبورد شاخص‌های کلیدی (نسخه تولید)

این پروژه یک وب‌اپلیکیشن کامل روی Cloudflare Workers + D1 است:

- **داشبورد** با ورود با رمز عبور مشترک (`public/index.html`)
- **بک‌اند** با API، پایگاه‌داده و ربات تلگرام (`src/worker.js`)
- **ربات تلگرام** برای دریافت خودکار گزارش فروش از مغازه‌داران
- **وبهوک عمومی** برای اتصال وب‌اپ پرو مجازی (ارسال بازدید/استفاده)

---

## ۱. پیش‌نیازها

```bash
npm install -g wrangler
wrangler login
```

یک حساب Cloudflare رایگان کافی است (حجم فعلی این پروژه کاملاً در سقف رایگان D1 و Workers جا می‌شود).

---

## ۲. ساخت پایگاه‌داده

```bash
cd farsh-kpi-system
wrangler d1 create farsh-kpi-db
```

خروجی این دستور یک `database_id` می‌دهد. آن را داخل `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_DATABASE_ID` کنید.

سپس جدول‌ها را بسازید:

```bash
wrangler d1 execute farsh-kpi-db --remote --file=./schema.sql
```

---

## ۳. تنظیم رمزهای محرمانه (Secrets)

```bash
wrangler secret put ADMIN_PASSWORD
# رمز ورود به داشبورد مدیریت را وارد کنید

wrangler secret put SESSION_SECRET
# یک رشته تصادفی و طولانی (مثلاً خروجی: openssl rand -hex 32)

wrangler secret put TELEGRAM_BOT_TOKEN
# توکنی که از @BotFather در تلگرام گرفته‌اید

wrangler secret put TELEGRAM_WEBHOOK_SECRET
# یک رشته تصادفی دیگر، برای امن‌کردن آدرس وبهوک تلگرام (مثلاً: openssl rand -hex 16)

wrangler secret put TRYON_API_KEY
# یک کلید تصادفی که فقط وب‌اپ پرو مجازی آن را می‌داند
```

### ساخت ربات تلگرام
۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
۲. دستور `/newbot` را بزنید و نام و یوزرنیم دلخواه انتخاب کنید.
۳. توکنی که می‌دهد را در مرحله بالا (`TELEGRAM_BOT_TOKEN`) وارد کنید.

---

## ۴. دیپلوی

```bash
wrangler deploy
```

آدرس خروجی چیزی شبیه `https://farsh-kpi-system.<your-subdomain>.workers.dev` خواهد بود.

### فعال‌سازی وبهوک تلگرام
با مقدار `TELEGRAM_WEBHOOK_SECRET` که ست کردید، این دستور را (یک‌بار) اجرا کنید — به‌جای مقادیر داخل `<>` مقدار واقعی بگذارید:

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<YOUR_WORKER_URL>/api/telegram-webhook/<TELEGRAM_WEBHOOK_SECRET>"
```

پاسخ باید `"ok":true` باشد.

---

## ۵. استفاده روزمره

### افزودن مغازه‌دار جدید
۱. وارد داشبورد شوید → تب «مغازه‌داران» → «افزودن فروشگاه».
۲. یک کد ۶ کاراکتری ساخته می‌شود.
۳. این کد را برای مغازه‌دار در تلگرام بفرستید و بگویید ربات را با نام کاربری ربات‌تان پیدا کند، `/start` بزند و کد را ارسال کند.
۴. پس از ارسال کد صحیح، فروشگاه به‌طور خودکار «متصل» می‌شود و منوی گزارش‌دهی برایش نمایش داده می‌شود.

### گزارش‌دهی روزانه مغازه‌دار (از طریق دکمه‌های ربات)
- 📦 ثبت فروش نقدی امروز (تعداد سپس مبلغ)
- 💳 ثبت فروش اقساطی امروز (تعداد سپس مبلغ)
- 🔁 درخواست انتقال کالا از انبار دیگر
- ✅ اعلام تأمین‌شدن یک درخواست انتقال
- ⚠️ ثبت شکایت مشتری از پرو مجازی

هرکدام از این گزارش‌ها مستقیماً در جدول `reports` ذخیره و در داشبورد به‌صورت شاخص‌های خودکار محاسبه می‌شود.

## ۶. اتصال وب‌اپ پرو مجازی

هر بار که مشتری وارد صفحه پرو مجازی می‌شود یا پرو را شروع/تمام می‌کند، وب‌اپ پرو مجازی باید این درخواست را بفرستد:

```js
fetch("https://<YOUR_WORKER_URL>/api/tryon-event", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "<TRYON_API_KEY>"   // همان مقداری که در مرحله ۳ ست کردید
  },
  body: JSON.stringify({
    event_type: "visit",       // یا "tryon_start" یا "tryon_complete"
    session_id: "abc123",      // شناسه بازدید مرورگر کاربر
    store_code: "AB12CD",      // اختیاری؛ کد فروشگاهی که مشتری از آن مراجعه کرده (اگر قابل تشخیص است)
    product_id: "carpet-118"   // اختیاری؛ کد فرشی که پرو شده
  })
});
```

اگر وب‌اپ پرو مجازی توسط تیم دیگری ساخته می‌شود، کافی است همین سه خط کد را به آن‌ها بدهید.

## ۷. چه چیزی خودکار است و چه چیزی دستی؟

| نوع | شاخص‌ها | منبع |
|---|---|---|
| **خودکار** | فروشگاه فعال، پوشش جغرافیایی، نرخ استفاده پرو مجازی، نرخ استفاده شبکه موجودی، نرخ استفاده اقساط، نرخ مشتری حفظ‌شده، سهم فروش اقساطی، نرخ شکایت | ربات تلگرام + وب‌اپ پرو مجازی |
| **دستی** (وارد کردن در همان داشبورد) | نرخ جذب فروشگاه، نگه‌داشت ۶ماهه، شکاف نرخ تبدیل، تغییر سبد خرید، هزینه پیاده‌سازی، افزایش فروش، ROI، CAC، NPS، نرخ نکول اقساط | نیاز به منابعی خارج از این سیستم (CRM فروش، حسابداری، نظرسنجی، سامانه‌های اقساط) دارند |

اگر بعداً به API واقعی دیجی‌پی/ترب‌پی/اسنپ‌پی یا سیستم صندوق فروشگاه‌ها دسترسی گرفتید، شاخص‌های دستی «نرخ نکول» و «سهم اقساط دقیق» و «تغییر سبد خرید» هم قابل خودکارسازی هستند — کافی‌ست یک وبهوک مشابه `/api/tryon-event` برایشان اضافه شود.

## ۸. توسعه محلی (اختیاری)

```bash
wrangler dev
```

این دستور یک نسخه محلی روی `http://localhost:8787` بالا می‌آورد که به D1 محلی (شبیه‌سازی‌شده) وصل است.
